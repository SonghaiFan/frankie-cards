# Frankie Cards / character blue and green

Generated from `../frankcards-app-icon.svg`. Run `npm run icons:composer` after editing the master.

- `01-background.svg`: opaque white icon canvas, #FFFFFF.
- `02-kiki-card.svg` / `02-kiki-symbol.svg`: green rear card and original Kiki at its top right.
- `03-bouba-card.svg` / `03-bouba-symbol.svg`: blue front card and original Bouba at its top right.

Card colours come from the original FemaleFigure/MaleFigure clothing. The editable Icon Composer document is `../AppIcon.icon`. Card surfaces have native specular lighting, a neutral shadow (0.35), and a light-to-base gradient; symbols have glass disabled, and card translucency is disabled. The original paths are preserved and transformed only. Do not bake a rounded enclosure into the layers. The web logo is flat and transparent; the cropped `public/frankie-cards-symbol.svg` is used beside lowercase cards beneath the original signature.

Apple workflow: https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer
